# Baza danych

W tym folderze są skrypty SQL tworzące bazę TaskBoard, konta MySQL z uprawnieniami oraz przykładowe zapytania.
Folder `backup/` zawiera kopię bazy do odtworzenia, a `migrations/` zmiany dla istniejącej bazy.
Instrukcja przygotowania bazy i połączenia z serwerem znajduje się w głównym README projektu.
