# Sprawdzenie dostępności i HTML

Sprawdzenie wykonano 19.11.2026 lokalnie w Chrome,
za pomocą Lighthouse 12.8.2.

| Widok | Accessibility |
| --- | ---: |
| Logowanie i rejestracja | 100 |
| Lista tablic | 100 |
| Tablica z zadaniami | 96 |
| Panel administratora | 100 |

Wszystkie widoki spełniają wymaganie co najmniej 90 punktów.
Na tablicy Lighthouse zgłosił zbyt niski kontrast części
elementów. Wyniki dotyczą widoków z zamkniętymi oknami
formularzy.

Cztery pliki HTML sprawdzono lokalnym Nu Html Checker
23.4.11. Walidator nie wykazał błędów.
Wynik znajduje się w pliku [html-validation.json](html-validation.json).
